# Site structure

## Purpose

A concise companion for scientifically literate readers. The paper provides derivations, primary results, validation details, and references. The website provides orientation and selected supplementary material.

## Public routes

- `/`: premise, time-dependent illustrative concept-cluster ablation, current interpretation, and one supplementary-material gateway.
- `/supplement/`: robustness checks, assignment diagrams, joint-null distributions, look-elsewhere/ranking comparisons, target-versus-context figures, and source data.
- `/supplement/concept-anchors/`: all 50 descriptions, aliases, and paraphrase sets.
- `404.html`: an editorial recovery page with homepage and supplement links.

The header links directly to the unified supplementary material. Manuscript and analysis links remain release reminders until public destinations are supplied.

## Scientific boundaries

The manuscript version and review date live in `content/paper-snapshot.ts`, not in the public hero. The site does not treat the Higgs assignment artifact as evidence, imply identical rankings across encoders, or equate target-cell significance with a global test.

## Presentation

Preserve the warm paper, Newsreader serif, compact sans-serif navigation, thin rules, and aspect-ratio-aware figures. Raster plots use multiply blending to integrate white backgrounds with the page; vector PDFs remain available for the study plates. Motion must respect reduced-motion preferences.

## Delivery

GitHub Pages serves a static export under `/geometric-signatures-companion-website/`. Only files in the selected public asset set are shipped. Hidden and historical material is kept outside the public repository.
